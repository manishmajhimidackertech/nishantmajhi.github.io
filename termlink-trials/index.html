HOW THIS WORKS

Every mission has an objective that can only be solved by typing a real ANSI/VT100 escape sequence into the input box.

  • Sequences look like \x1b[31mHELLO\x1b[0m - you can type \x1b, \033, or \u001b for the escape character.
  • The terminal above the input updates live as you type, so you can see the effect before submitting.
  • Press EXECUTE (or Enter) to check your work against the mission's objective.
  • Stuck after a couple of tries? A hint unlocks automatically - or request one any time.

A short calibration mission comes first with the answer given outright, just to get the mechanics under your fingers.
